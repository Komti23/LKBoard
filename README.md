## ✨ Ключевые возможности

### 🌐 1. Совместная работа в реальном времени (Live Collaboration & Web Sharing)
- **Раздача доски в 1 клик**: Встроенный сервер на базе стандартного JDK HttpServer — без сторонних облачных зависимостей.
- **Интерактивный веб-клиент для браузеров**: Человек, которому вы отправили ссылку, может открыть её на любом устройстве (**Windows, Mac, iPad, iPhone, Android**) в **Chrome/Safari/Edge**, видеть доску в реальном времени, рисовать маркером, добавлять стикеры и отмечать задачи.
- **Desktop-to-Desktop P2P**: Прямое подключение второго экземпляра приложения LKBoard по протоколу `lkboard://connect` или IP:Port.
- **Курсоры участников**: Отображение положения мыши, именных бейджей и лазерных указок всех подключенных пользователей.
- **Поддержка глобального доступа**: Совместимость с ngrok и Cloudflare Tunnel для работы через Интернет.

---

### 🗂️ 2. Интерактивные стикеры с To-Do чекбоксами (Sticky Notes)
- **Палитра**: 6 пастельных оттенков (солнечный жёлтый, мятный, коралловый, небесный, лавандовый, стеклянный белый).
- **Эффект бумаги**: Мягкая глубинная тень и загнутый уголок листа.
- **Динамический шрифт**: Размер шрифта плавно масштабируется под объём текста.
- **Кликабельные To-Do чекбоксы**: Строки вида `- [ ] Задача` превращаются в интерактивные чекбоксы, которые можно отмечать прямо на холсте в 1 клик.
- Горячая клавиша: **`S`** или двойной клик для вызова расширенного редактора.

---

### ⏱️ 3. Плавающий таймер воркшопов и Pomodoro
- Стеклянная капсула в правом верхнем углу холста с возможностью свернуть в компактную пилюлю (Pill).
- **Два режима**: Обратный отсчёт и Секундомер.
- **Быстрые пресеты**: 5 мин, 15 мин, 25 мин (Помодоро), 45 мин (урок) и кнопка **+1 мин**.
- **Синтезированный звуковой гонг**: Гармонический аккорд $C_5 + E_5 + G_5$ через чистый Java Sound API (100% офлайн, без внешних mp3-файлов).
- Автоматически отображается в полноэкранном зрительском режиме (`F5`).

---

### 📋 4. Канбан-доски на холсте (Kanban Boards)
- 4 фирменные колонки: **«Бэклог»** (🔴), **«В работе»** (🟡), **«На ревью»** (🟣), **«Готово»** (🟢).
- **Живые счётчики**: Автоматический подсчёт задач в каждой колонке.
- **Магнитная смена статусов (Drag & Drop)**: Перетаскивание карточки вехи в колонку автоматически меняет её статус и цветной бейдж.
- Горячая клавиша: **`K`** или **`Ctrl+Shift+K`**.

---

### 🧲 5. Умные коннекторы и фигуры (Smart Connectors & Shapes)
- **Магнитная привязка**: Соединительные линии и стрелки привязываются к граням фигур.
- **3 стиля линий**: Прямая, ортогональная (ступенчатая для блок-схем) и плавная кривая Безье.
- **Большой набор фигур**: Прямоугольники, скругленные блоки, эллипсы, ромбы, стрелки, выноски, облака и 3D-фигуры (куб, цилиндр, конус, пирамида, сфера).

---

### 🏷️ 6. Карточки вех дорожных карт (Milestone Cards)
- Интерактивный статус в 1 клик (🔴 Бэклог, 🟡 В работе, 🟢 Готово, 🟣 На ревью).
- Визуальный прогресс-бар выполнения (0–100%).
- Бейджи дедлайнов и теги направлений (Backend, Frontend, Release, v1.0).

---

### 📈 7. Построение графиков функций (Desmos-style Math Engine)
- Встроенный математический анализатор формул: `sin(x)`, `cos(x)`, `x^2 - 4`, `sqrt(x)`, `abs(x)` и др.
- Декартова сетка с осями X/Y, разметкой делений и настраиваемым диапазоном `[xMin, xMax]`.
- Мгновенное добавление на холст по клавише **`G`**.

---

### 📄 8. Презентации и документы (PDF & PPTX Frame Viewer)
- Вставка презентаций PowerPoint (`.pptx`) и документов (`.pdf`) в виде интерактивных фреймов на холсте.
- Постраничная навигация, плавный зум и перелистывание слайдов во время уроков и созвонов.

---

### 🎯 9. Режим презентации и Неоновая лазерная указка
- **Полноэкранный режим (`F5`)**: Скрывает все панели управления и фокусирует внимание на материале.
- **Лазерная указка (`L`)**: Оставляет яркий светящийся след, плавно растворяющийся через 1.5 секунды.

---

### 📏 10. Умные направляющие (Smart Alignment Guides)
- Магнитное выравнивание по центрам и краям соседних карточек (как в Figma).
- Индикаторы равного расстояния (Equal Spacing) для аккуратного построения диаграмм.

---

### 📤 11. Экспорт и обмен данными
- **Векторный SVG**: Доска сохраняется в кривых без потери качества при любом масштабе.
- **Векторный PDF**: Идеально для печати конспектов и методичек.
- **Высококачественный PNG**: До 4000px с прозрачным или цветным фоном.
- **Быстрый снимок в буфер (`Ctrl+Shift+C`)**: Мгновенная вставка в Telegram, Discord, Slack.

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
| :--- | :--- |
| **`1`** или **`V`** | Инструмент выделения (Select) |
| **`Q`** или **`P`** | Стилус / Перо (Pen) |
| **`E`** | Ластик (Eraser) |
| **`H`** или **Пробел + Drag** | Рука / Панорамирование (Hand) |
| **`S`** | Создать стикер с To-Do чекбоксами (Sticky Note) |
| **`K`** | Канбан-доска (Kanban Board) |
| **`R`** | Геометрические фигуры (Shapes) |
| **`C`** | Соединительная линия / Коннектор (Connector) |
| **`M`** | Карточка вехи дорожной карты (Milestone Card) |
| **`G`** | График математической функции (Function Graph) |
| **`T`** | Текстовый блок (Text) |
| **`F`** | Фрейм для документов и презентаций |
| **`L`** | Лазерная указка (Laser Pointer) |
| **`F5`** | Полноэкранный презентационный режим |
| **`Ctrl + Z`** / **`Ctrl + Y`** | Отменить / Повторить действие (Undo / Redo) |
| **`Ctrl + C`** / **`Ctrl + V`** | Копировать / Вставить элементы |
| **`Ctrl + Shift + C`** | Скопировать изображение доски в буфер обмена |
| **`Ctrl + D`** | Дублировать выделенные элементы |
| **`Ctrl + A`** | Выделить всё содержимое |
| **`Ctrl + 1`** | Подогнать масштаб под всё содержимое (Zoom to Fit) |
| **`Delete`** / **`Backspace`** | Удалить выделенные элементы |
| **`Ctrl + H`** / **`Esc`** | Вернуться на Главный экран (Менеджер досок) |

## 🛠️ Сборка и запуск

### Требования
- **JDK 21** (Microsoft OpenJDK, Eclipse Temurin или Oracle JDK 21).
- ОС: Windows 10/11, macOS (Intel/Apple Silicon) или Linux.

### Быстрый запуск на Windows (скрипты в 1 клик)
- **`run.bat`** — запуск приложения LKBoard
- **`build-exe.bat`** — сборка автономного Windows-инсталлятора (`.exe`) со встроенным JDK
- **`test.bat`** — запуск полного набора юнит-тестов
- **`update.bat`** — получение обновлений из Git и сборка

### Запуск в режиме разработки
```bash
# Windows
.\gradlew.bat run

# macOS / Linux
./gradlew run
```

### Сборка исполняемого пакета (Installer / Exe / Msi)
```bash
# Windows installer (.exe / .msi)
.\gradlew.bat packageReleaseDistributionForCurrentOS
```
Готовый дистрибутив будет сгенерирован в каталоге `build/compose/binaries/main/`.

## 🏗️ Архитектура проекта

```
LKBoard/
├── src/jvmMain/kotlin/com/lkboard/app/
│   ├── collaboration/       # Сервер совместной работы (HTTP/SSE), Web-клиент и CollabManager
│   ├── clipboard/           # Работа с системным буфером обмена (изображения, текст, элементы)
│   ├── data/                # Сериализация JSON (.lkboard), BoardManager, шаблоны
│   ├── export/              # Экспорт в векторный SVG, PDF и PNG
│   ├── history/             # Паттерн Command (Undo/Redo с неограниченной историей)
│   ├── model/               # Модели данных: BoardElement, BoardState, SmartGuides, ShapeModel
│   ├── timer/               # Синтезатор звука AudioChimePlayer и WorkshopTimer
│   ├── ui/
│   │   ├── canvas/          # InfiniteCanvas, CanvasGestures, GridRenderer
│   │   ├── components/      # Стеклянные диалоги, тулбары, ElementRenderer, GlassToolbar
│   │   ├── dashboard/       # Главный экран управления проектами досок
│   │   └── viewmodel/       # BoardViewModel — единый источник истины
│   └── util/                # Парсер математических формул, сглаживание штрихов (Bezier)
├── build.gradle.kts         # Конфигурация Kotlin Multiplatform & Compose Desktop
└── README.md
```
